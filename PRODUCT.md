# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React and Node.js with Express, Sequelize and MySQL. The user explicitly chose Node.js instead of the assignment's Laravel backend.

## Users

People maintaining a small task list and an interviewer reviewing a practical assignment.

## Product Purpose

Create, view, edit, delete and change the status of tasks with a clear responsive interface.

## Operating Context

Desktop-first task table and phone cards, confirmed by the user. One shared task collection without account management. The user requested implementation and delegated the best design choice to Impeccable.

## Capabilities and Constraints

Preserve title, optional description, the exact statuses Pending / In Progress / Completed, optional due date, the five original CRUD endpoints, confirmation before deletion, status filtering, loading and error/success feedback. One repository with backend and frontend folders. No test cases or automated test tooling are requested now. Local build and direct runtime checks remain appropriate implementation work. No additional business modules.

## Brand Commitments

No existing visual brand was supplied. The user delegated visual direction and asked for an impressive UI. Working product name: Taskline, with task semantics unchanged.

## Evidence on Hand

The supplied assignment and plan.md. No user data, customer claims, imagery or existing UI.

## Product Principles

- Task content leads; status and due dates remain easy to scan.
- Every write is confirmed by the real API and persistent MySQL storage.
- Recover from failures without discarding drafts or falsely claiming success.
- Keep the small application understandable and easy to install.
